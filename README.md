# linux-security-homelab

## Objective
This repository documents the development of a Linux-based security homelab focused on system hardening, monitoring, and incident response fundamentals.

## Environment
- Host: Windows 11
- Hypervisor: Oracle VM VirtualBox
- Guest OS: Ubuntu Server 22.04 LTS
- RAM Allocated: 4GB
- CPU: 2 cores
- Network Mode: NAT

## Phase Plan

### Phase 1 – Foundations
- Linux command line fundamentals
- User and permission management
- System updates and patching

### Phase 2 – System Hardening
- UFW firewall configuration
- SSH hardening
- Fail2Ban setup
- Log analysis

### Phase 3 – Detection & Monitoring (Future)
- IDS/IPS deployment
- SIEM integration
- Attack simulation (controlled environment)

---

This lab is being built progressively to strengthen practical Linux and cybersecurity skills aligned with SOC and security analyst roles.
